# NUTLAB - Kalitenin Adresi

NUTLAB resmi web sitesi - Premium kuruyemiş ve çerez satış platformu.

## 🌟 Özellikler

- **SEO Optimized**: Meta taglar, Open Graph ve Twitter Cards
- **Performance**: Lazy loading, optimized images ve cache headers
- **Responsive**: Mobil ve desktop uyumlu tasarım
- **Fast Loading**: Optimized Google Fonts ve CSS

## 🚀 Ürünler

- **Ekonomik Karışık Çerez**: Çerezimizin içinde diğer paketlere göre daha az kaju ve antep fıstığı
- **Lüks Karışık Çerez**: Antep fıstığı ve kaju bulunur, fıstık ve fındık ağırlıklı
- **Special Çerez**: Ceviz, bolca kaju ve antep fıstığı içeren premium karışım
